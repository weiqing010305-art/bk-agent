# 青禾 · AI Banking Mock

面向金融科技大赛的第一阶段 Web 演示：以聊天作为主要入口，覆盖智能转账、账单分析、订阅管理、卡片管理。桌面和手机均可使用。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

浏览器打开 <http://127.0.0.1:5173/>。如需检查，运行 `npm test`、`npm run build`；浏览器流程检查需要本机安装 Microsoft Edge，并在启动开发服务后运行 `npm run test:e2e`。

## 演示范围

- 点击首页四张业务卡片，或输入包含“转账”“账单”“订阅”“卡片”的自然语言，展开对应操作卡片。
- 对话区独立滚动，新回复会自动进入视野；切换业务后旧操作卡片收起，可点“重新打开”。输入框始终保留在底部。`Ctrl/⌘ + K` 可开始新对话。
- 转账先核对收款人、账户和金额，再模拟执行。确认后余额、右侧概览和账单明细同步变化；余额不足会拦截。
- 订阅可模拟取消，月度待扣金额同步变化；卡片可模拟冻结和解冻，状态同步变化。
- 演示状态保存在当前浏览器的 localStorage。桌面右侧或手机菜单中的“重置演示数据”可恢复初始样例。

这是**本地前端 mock**：聊天回复按预设规则生成，资金、交易、卡片及订阅均为虚构数据，不连接真实银行或 AI 服务。演示日期固定为 2026 年 9 月 25 日。
