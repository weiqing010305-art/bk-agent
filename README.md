# 青禾 · 银行 AI 资金管家（bk-agent）

面向个人客户的 AI Banking Agent 参赛项目。产品希望让用户用自然语言提出银行业务需求，并通过可核查的账单、账户信息和确认步骤完成操作。**当前仓库已交付第一阶段 Web mock**：以聊天为主要入口，优先展示智能转账、账单分析、订阅管理和卡片管理。

## 当前进度

| 阶段 | 范围 | 状态 |
|---|---|---|
| 第一阶段：前端 mock | 响应式 Web chatbot、四项核心业务、统一模拟数据 | 已实现，可本地运行 |
| 后续阶段：AI Agent | 意图理解、业务工具调用与授权流程 | 尚未接入 |
| 扩展方向 | 现金流预警、目标资金计划等 v2.0 设计构想 | 暂不纳入当前 mock |

这个项目聚焦具体的银行业务，不做通用金融问答。用户可以提出“给张三转 100 元”或“这个月花了多少”这样的需求；当前 mock 会按关键词进入对应流程，具体收款人与金额仍需在卡片中填写。产品目标是让分析结果能追溯到交易，让重要操作能先核对再确认。更长周期的资金规划是历史设计稿中的后续方向。

## 运行 mock

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

打开 <http://127.0.0.1:5173/>。运行 `npm test` 检查模拟账本，运行 `npm run build` 检查构建。启动开发服务后，安装 Microsoft Edge 的机器可运行 `npm run test:e2e` 检查浏览器流程。

## 当前可体验的业务

| 业务 | mock 中可操作的流程 | 数据反馈 |
|---|---|---|
| 智能转账 | 选择常用收款人、填写金额与备注、核对后确认 | 余额减少，新增一笔转账账单；余额不足会拦截 |
| 账单分析 | 查看九月收支、分类分布，筛选交易明细 | 与转账后的账本保持一致 |
| 订阅管理 | 查看自动续费项目，确认模拟取消 | 项目状态与预计下月扣费同步变化 |
| 卡片管理 | 查看两张样例卡，确认模拟冻结或解冻 | 卡片状态同步变化 |

首页提供四项业务快捷入口，也可输入包含“转账”“账单”“订阅”“卡片”等关键词的消息。对话区独立滚动，输入框固定在底部；切换业务后，旧操作卡片收起，可点“重新打开”。`Ctrl/⌘ + K` 可开始新对话。

所有余额、交易、卡片和订阅均为**虚构演示数据**，聊天回复由预设规则生成；当前没有接入真实 AI 模型、银行系统或支付通道。模拟转账和取消订阅不会产生真实操作。演示日期固定为 2026 年 9 月 25 日。状态保存在本机浏览器的 localStorage；桌面右侧或手机菜单中的“重置演示数据”可恢复样例。

## 实现概览

当前代码使用 React 19、JavaScript/JSX、Vite 和 CSS 实现 Web 页面；业务样例和状态变更在浏览器端完成。`src/bank.js` 保存模拟账本逻辑，`src/main.jsx` 实现对话与业务卡片，`src/style.css` 提供基础布局，`src/refinement.css` 统一可读性、业务卡片和手机适配。当前界面保留青禾绿色三栏布局，将首页快捷业务整理为列表，增大正文和操作控件，并使用本地字体栈避免外部字体加载影响。测试包括 Node.js 单元测试及基于 Playwright 的浏览器流程检查。
