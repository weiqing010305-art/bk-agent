# Agent 多组输入与链路验证 · 2026-10-26

对当前提交 3af51a9 的本地合并应用进行测试；新增和调整的是测试脚本，生产业务代码未改动。模型使用本机现有配置。每个独立样例新建虚构账户；连续对话在各自账户内保持同一聊天。没有真实银行、运营商或资金调用。

## 结果口径

- 首轮扩展矩阵 **35/37 通过**，不能描述为一次全部通过。
- 两项未过：一项是测试错误地要求唯一姓名片段“陈”不能匹配；目录只有陈晨，现有逻辑允许唯一匹配。修正测试预期后重测通过。另一项“我想手机充值”返回模型处理 503，随后独立重测三次均正常；本轮无法确定首次 503 是模型响应校验还是服务延迟导致。
- 增加多匹配姓名、503 重试回执、候选选择与完成后再办，共 **40 组最终场景**，首轮结果与针对性复测合并后均通过。这是有限样本和失败恢复验证，不代表模型调用永远成功或所有表述均能正确识别。

## 复跑与证据

启动 `npm start` 后，在本机 PowerShell 设置 `AGENT_LIVE_TEST=1`、`BASE_URL=http://127.0.0.1:8080` 及可用的 `BROWSER_PATH`，运行 `npm run test:agent:matrix`。完整运行会调用配置模型并在新虚构账户写测试交易，可能产生模型费用。

`AGENT_MATRIX_ONLY` 可按场景名称筛选；`AGENT_MATRIX_REPORT` 可指定独立结果文件。默认 `.local/agent-matrix-results.json`。本次原始首轮 `.local/agent-matrix-initial-20261026.json`、分项复测及合并 `.local/agent-matrix-final-20261026.json` 均保留，未覆盖首轮失败，也不保存密码或密钥。合并结果为 40/40，明确包含复测。
