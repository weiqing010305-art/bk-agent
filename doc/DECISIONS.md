## §1 已定

### D-01 · 单页上限 150 字

界面文案 ≤150 字；**数据不计入**。超了 = 设计不够好。

```mermaid
flowchart LR
    P["一屏"] --> C{"界面文案<br/>标签/标题/说明/按钮"}
    C -->|"≤150"| OK["通过"]
    C -->|">150"| X["返工：用设计替代文字"]
    P -.->|"不计入"| DATA["数据：列表行/金额/日期"]
```

`npm run test:text` ｜ 原话 U-06

### D-02 · 界面不留演示备注

用户可见处不出现「演示 / 模拟 / 预设规则 / 占位」。代码注释保留。

```mermaid
flowchart LR
    T["一句话"] --> W{"渲染到屏幕上？"}
    W -->|"是"| DEL["删掉"]
    W -->|"否（代码注释）"| KEEP["保留 —— 那是文档"]
    DEL --> SCAN["test:copy 扫<br/>含 title / aria-label / placeholder"]
```

原话 U-07

### D-03 · 用设计代替文字

能用一个图标 + 一个数字说清的，不写一句话。层级靠视觉权重，不靠副标题。

```mermaid
flowchart TB
    E["一个元素"] --> Q{"删掉文字后<br/>3 秒内能猜对吗？"}
    Q -->|"能"| D["用设计<br/>图标/位置/分组/颜色"]
    Q -->|"不能"| T["留最短的文字<br/>视觉权重压到最低"]
```

原话 U-05
