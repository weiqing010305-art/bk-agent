## 2026-09-28 · Agent 统合视图 + 图表化账单 + 多 Agent 分工

每办一件事就往对话里贴一张卡，看到第三张就得往上滑 —— 那违背最小操作原则。

### Agent 统合视图（agent/brief.js）

软件时代的银行按「产品」切信息：余额在账户页、账单在账单页、订阅在订阅页，用户自己拼。
Agent 时代按「用户此刻要办的事」把跨产品的信息合起来。所以每个 compose* 都刻意跨域取数：

- **首页** = 一张状态板：余额 / 本月支出 / 待扣订阅 + 需要留意的 + 最近三笔
- **账单** = 结论在前、分析居中、明细在后；结论句会把订阅这个「另一个产品页的事」拉进来
- **转账核对** = 不只收款人和金额，还给「转后余额」「本月支出会变成多少」「扣完订阅还剩多少安全垫」
- **转账回执** = 钱去哪了 + 账户现在什么样 + 接下来你可能想做什么

### 工作区模型（取代无限增长的聊天流）

助手页从「一条会滚走的聊天流」改成 **工作区 + 一行可切换的历史**：
工作区放当前这件事的统合视图（一屏看全），历史折成一行 chips，点一下换回当时那张视图，
并给一个「回到最新」。**不滚动的历史，可切换的现在。**

### 图表化

新增 `views/charts.jsx`：手绘 SVG，零依赖。圆环 / 条形 / 累计折线三种形态，
**共享同一个「当前分类」状态** —— 鼠标滑过任一形态的任一段，图例、中心数字、扇形一起响应。
账单页顶部有形态切换 tab。

### 卡片与卡包

卡片补上了真实银行会有的字段：额度、本月已用、可用渠道、发卡日。
卡包可切换，选中的卡浮起；卡片页有额度统计条、卡片事实、操作宫格、这张卡的流水。

### 动线必须是无感的

删掉了右侧的「动线面板」和侧边栏的「隐藏动线面板」按钮 —— 那是我把「动线」理解错了。
动线是用户体验的顺滑度，不是给用户看的流程图。

### 修的真 bug

- **卡片扫光吃掉光泽层**：光泽和扫光抢同一个伪元素，hover 时那层灰光突然消失，观感像闪了一下。拆成 `::before` / `::after`。
- **`Figure` 的 `note` 没走引用解析**：`{path}` 对象被直接丢给 React，报 Objects are not valid as a React child。
- **统合视图把金额字面量拼进了组件结构** —— 我自己的测试抓到的，测试是对的：planner 只允许产出引用。已把成句结论移到 service 层。
- 视频扫光从 880ms 放慢到 1400ms（太快像故障闪烁）。

### 结构

产品层按页面拆成 `views/pages/*.jsx`，一个页面一个文件、一个 owner；
共用零件在 `views/parts.jsx`，分类视觉语言在 `views/shared.jsx`。
`App.jsx` 抽出 `useTransferFlow` 与 `useUndoWindow`，回到 297 行。

### 多 Agent 分工

四个页面 owner 并行工作（卡片与卡包 / 账单与图表 / 订阅与转账 / 概览与收款人），
每个 agent 独占自己的文件，基础层（tokens / a2ui / agent / services）冻结不动。

## 2026-09-28 · 审美打磨（impeccable / taste-skill / emilkowalski 三项技能落地）

三份前端技能已拉进 `vendor/skills/`，本轮**实际逐条应用**，不是只当资料囤着。

**按 impeccable 的 `craft-floor` 硬禁令清理**
- 删掉 `feTurbulence` 噪点层（codex 规则：读起来像业余作品）
- 删掉所有 eyebrow/kicker（原文：「这是一个 ban，没有 brief 能换回来」）。转账/账单/订阅/卡片四处的标题上方小标签全部移除
- 修 ghost card：面板原先同时有 1px 边框和大阴影，现在**只声明一次 elevation**（用阴影）；可点胶囊反过来只留边框
- 卡片半径 18 → 16px（规则：卡片半径 12–16px）

**主题化「浏览器表面」**（craft-floor 说这是模型最容易漏、也最能看出「是造出来的还是拼出来的」）

**按 taste-skill 的 AI-Tells 黑名单清理**

- **「张三」「李四」换成「章明远」「李思远」**（它们是中文的 John Doe，黑名单点名）

**降低饱和度**
- 卡面从高饱和薄荷/亮蓝改成低饱和浅色 + 深色文字。两个原因：大面积高饱和是「太艳」的主因；白字压薄荷绿只有 2.7:1，达不到 craft floor 的 3:1，浅底深字能到 7:1

**动效按 emilkowalski 的规则校准**
- `--ease-in-out` 从 CSS 内置形状换成强曲线 `cubic-bezier(.77,0,.175,1)`
- 7 处 hover 补上 `and (pointer: fine)`（触屏 tap 会误触发 hover）
- 按压区间统一到 0.95–0.98
- 按「频率门」：一天看几十次的列表行只该有几乎不可感知的动效，餐饮/购物的签名动作从无限循环改成**一次性**
- **新增「对焦」切换动效**：切换产品层页面时内容从轻微失焦落到清晰。craft-floor 要求动效不要只停在 transform/opacity，blur 也属于调色板

**按众安银行的落地建议重做产品层信息架构**
- **概览从 6 段砍到 3 段**：删掉「下次自动扣费」「卡片状态」两个面板（侧边栏已有独立页，首页再放是重复）、删掉支出分布和双数字 stat-grid
- **新增 4×2 快捷宫格**：上排圆形=动作，下排方形=产品。这条双图标语言是本次调研里最高杠杆的一招
- 新增 `StatBar`（双列统计条，4 处复用）与 `IconTile`；`.tx-row`/`.sub-row` 合并为统一的 `Row`
- 交易明细**按日期分组**（原来 12 行平铺），分析移到明细之后
- 订阅拆成「生效中 / 已取消」两组
- 新增两个产品面：**收款人**、**回执**
- **★ 5 秒可撤销**：转账确认后不立刻记账，先给 5 秒窗口和倒计时条，可撤销。这是 ZA 最值得抄的一条，解决的正是「错手转账」

**修了一个真 bug**

## 2026-09-28 · 两层架构 + 产品层 + 动效

**两个入口，一个内核。** 此前只有一个 ChatBox —— 那是业务层的入口，不该取代整个产品。

- **补上产品层**：新增概览 / 账单 / 订阅 / 卡片 / 转账五个正常功能页。它们与助手共用同一份
  `services/banking.js` 的 dataModel，所以两边的数字永远一致（e2e 有断言守着）。
- **侧边栏常驻**，并且把两层分组摆在界面上：「业务层 · 对话」只有助手一项，「产品层 · 功能」是五个页面。
  历史对话移入侧边栏底部，不再用抽屉。
- **动线可视化面板**：一次交互摊成 6 步（入口 → 意图理解 → 取数（后台）→ 生成 UI 描述 → 校验并展开 → 渲染），
  并标出「要接后端时改哪里」——第 2/3/4 步是将来要替换的位置，第 5/6 步一行都不用动。
- **转账改为四步流程**：怎么转 → 转给谁 → 转多少 → 核对。
  一进来就问「转多少」太冒犯；先问「你想怎么转」。**已经说过的信息不重复问**：
  说「给张三转 100 元」直接进核对步，只说金额则从选收款人开始，什么都没说才从第一步开始。
- **分类视觉语言**：6 个分类各有图标、配色与底座形状（圆形=动作/方形=对象，来自 ZA Bank 的双图标语言）。
  餐饮支持「不同餐厅不同呈现」——图标靠关键词正则，配色靠名称哈希，同一家店永远同一套色。
- **订阅三条动效**：云空间 hover 上浮并带同步云影；视频 hover 一道斜向柔光扫过；音乐 hover 四根均衡器错峰起伏。
- **卡面按 ZA Card 实测几何重做**：1.669 宽高比、角对角渐变（不是 135deg）、零高光零纹理。
  冻结态改为墨黑+斜纹，不再用把文字也压灰的 grayscale。
- **动效基础设施**：入场滑入 + 列表错峰（纯 CSS `nth-child` delay，零 JS 循环）+ 弹簧曲线。
  并修了两个降级缺口：`prefers-reduced-motion` 漏重置 `animation-delay`（会让错峰项先隐形再弹出），
  以及均衡器不能加 `fill-mode: both`（降级时会塌成一条平线）。
- **样式拆为三个文件**（app / a2ui / motion），组件样式硬编码颜色保持 0 处。
- 样例数据增加 4 家餐厅，余额与两条测试断言同步更新（12 条流水、支出 5077.00）。
- `vendor/` 加入 .gitignore —— 那里是 GSAP 与几个前端技能库的参考 clone，约 150 MB，是教材不是依赖。
