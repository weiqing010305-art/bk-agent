# 模型设置实现计划

用户要求：“我需要个设置可以自己接入模型然后，配置api”。

在原助手入口旁增加全局设置按钮，弹窗沿用薄荷绿、浅蓝和白底。提供服务商预设、自定义 Base URL、模型名、隐藏输入的 API Key，支持测试连接、保存生效及清除配置。

1. 后端新增本机配置读写服务：仅返回地址、模型名、是否有密钥及版本；原子保存 .env，保留数据库等其他变量；保存后更新内存配置。
2. 连接测试使用相同结构化提取协议与固定测试文本，不保存、不读取账本；失败不覆盖有效配置，不回传服务商原始错误。
3. 设置接口依赖有效会话、本机来源及原 CSRF 检查；新目的地必须输入新密钥，禁止携带原服务密钥跨地址。
4. 原生 dialog 管理焦点与 Escape，窄屏适配；密钥不写 localStorage/sessionStorage，保存后清空输入，关闭即卸载。
5. 后端 mock 测试检查秘密不回显、版本冲突、地址限制、失败保存、即时生效和并发探测；浏览器 mock 测试检查入口、编辑、保留密钥、换地址、连接测试、关闭及手机布局。
6. 同步安全自评、架构、配置说明与变更记录。原支付和 Agent 任务不修改，不引入依赖，不改受保护架构。
