# Agent 思考加载与流式回复

目标：发送后立即显示薄荷色旋转图标与“思考中”，回复通过 SSE 分段显示，完成后才开放业务动作和自动跳转。

方案：保留原 JSON 协议，`Accept: text/event-stream` 时同一接口返回 thinking、delta、complete/error 事件。只对已经完成字段提取和服务端校验的用户回复分段，不显示模型内部推理或未校验 JSON。任务先提交数据库再发送回复；断线可按原 request_id 重试，不执行支付。

实现顺序：
1. 后端封装 SSE，沿用会话权限、CSRF、版本及幂等。
2. 前端增量解析 UTF-8、处理分包/错误/断线；消息更新绑定原聊天，新聊天不受旧流影响。
3. 思考图标、回复光标、滚动跟随及减少动态效果；动作在 complete 后出现。
4. 后端协议测试、分包解析单测、桌面/手机浏览器加载与增量显示测试，真实模型转账/充值回归；同步文档。

不新增依赖，不改变资金确认/密码流程，不修改受保护产品架构。
