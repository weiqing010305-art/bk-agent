# 手机充值 Agent 与错误业务链接修复

用户截图：说“我想手机充值”却被告知只支持转账，并出现“查看这笔转账”。根因是模型/后端只登记转账，前端对任意任务 ID 都渲染转账动作。

实现范围：

1. 候选提取增加 phone 意图与手机号字段；常见 11 位手机号发送模型前替换为 PHONE_n，后端恢复并验证。
2. 复用现有任务、归属、版本和整数分解析；缺手机号或金额时只追问，填齐后 handoff 到原手机充值页面的核对步。
3. 页面可修改手机号/金额，更新任务版本及支付 ID；支付携带任务引用，后端校验参数和版本，复用原充值接口的用户密码确认及幂等。
4. 前端依据 kind/can_open 渲染相应动作；无关回复不出现转账链接，手机任务显示充值链接。
5. 验证：隔离后端测试；模型手机号脱敏测试；mock 浏览器完整追问、跳转、修改、错密码不提交、正确密码与回执；原转账及十三业务回归。

本次不引入依赖，不改受保护产品架构。充值仍为虚构环境，沿用原支付密码，不宣称接入真实运营商。
