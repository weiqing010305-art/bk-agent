# Transfer Agent Implementation Plan

**Goal:** 实现对话补齐转账信息、校验后交接页面、用户确认与支付密码验证。
**Architecture:** 后端持久化任务；兼容 Chat Completions 的模型只提取带原文证据的字段。业务状态机负责追问、收款匹配、金额解析和权限；React 使用受限任务引用交接。
**Tech Stack:** 现有 React、FastAPI、SQLAlchemy、PostgreSQL、httpx；不新增依赖。

1. 新增 AgentTask 及凭据/操作认证字段迁移，验证迁移往返。
2. 新增后端模型适配与确定性字段校验，测试无配置、非法输出、金额与歧义处理。
3. 新增会话归属、版本控制、草稿查询/修改/准备接口；测试恢复、越权与幂等。
4. 接入聊天回合与转账核对页；保留现有手动入口与其他功能。
5. 新增支付密码验证路径，账户级失败锁定与后端累计风险升级；测试绕过与重复扣款。
6. 运行单元/后端/构建和浏览器流程检查，记录旧套件限制。
7. 更新安全自评、架构、配置和变更记录；模型未配置时明确交付限制，不伪造真实模型联调结果。

执行授权来自用户“那现在去做agent吧”。不自动提交或推送本次未审核的实现，不修改受保护产品架构。
